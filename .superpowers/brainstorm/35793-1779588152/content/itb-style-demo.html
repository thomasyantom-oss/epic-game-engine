Into the Breach 风格参考

ITB 的动画设计哲学：信息优先、极简精确、网格对齐

ITB 的核心特征 vs 传统 RPG 动画

❌ 传统 RPG（我之前展示的）
  • • 华丽的飞行弧线
  • • 数字飘散、缩放动画
  • • 角色做出夸张动作
  • • 粒子特效、光效叠加
  • • 感觉"酷"但信息密度低
✓ Into the Breach 风格
  • • 预告：行动前就显示会发生什么
  • • 几何化：直线、矩形、网格对齐
  • • 极短：每步 100-200ms，干脆利落
  • • 顺序：逐个结算，绝不同时
  • • 功能色：颜色传递信息，不做装饰

基于 ITB 风格的原语重定义

原语 ITB 对应 视觉表现 时长
strike_line 攻击方向线 从 actor 到 target 的直线闪过 150ms
impact 命中闪白 目标格短暂全白 100ms
damage_number 伤害数字 格子上方出现数字，短暂停留后消失 400ms
shake 目标抖动 token 水平小幅抖动 2-3 次 200ms
mark_dead 击杀标记 ✕ 叠加 + token 变暗 300ms
preview 意图预告 目标格橙色边框 + 预告数字（选择时，非结算时） 持续
