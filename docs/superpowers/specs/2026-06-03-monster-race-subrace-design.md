## 0. 一句话

怪物身份 = **种族 + 子种族 + 随机个体变异 + 正交 tag**,全部坐在引擎现成的 **base+modifier 底座(ModifierChain)+ schema 组合 + TagIndex** 上,不造新机制。

> **概念澄清(别弄错方向):** `modifier` 是个**通用底座**——"base + 一摞可插入属性"这种形状,任何实体(玩家/怪物/装备持有者)都能套,**不等于某个词缀系统**。本档讲的"**怪物个体变异**"是这个底座在**怪物域**的一种用法,描述"一个个体 vs 它族群里普遍个体"的差异;它和**装备词缀**(定义装备属性)是**分开的两个域系统**,只是恰好都坐在同一底座上——**不是一套引擎、不"对称"**。下文凡写 "modifier" 均指"怪物个体变异条目",非通用底座本身。

## 1. 设计动机

- 当前模拟器里 forest_goblin 的成长(5/级统一公式、`5+floor(gained²/38)` 武器 base)只是**压测脚手架**,不是最终(见 `project-core-combat-formulas` 的"脚手架"段)。真实怪物成长需要一套**可扩展、纯数据**的结构。
- 怪物需要一套**个体变异机制**:描述"一个个体 vs 它族群里普遍个体"的差异——同种族血统固定,个体变异随机。变异稀有的个体(如带灵魂的)涌现出"掉灵魂球 / 值得抓 / 掉好装"的玩法后果。**注:这是怪物侧的内容机制,不是装备产出引擎**(装备词缀是另一个域,见 §0 澄清)。
- 这套同时是 #3"怪物抗性内容"的家(子种族/个体变异带 flat % 抗),也是宠物资质的**初始基调来源**。

## 2. 组合模型(四层正交)

```
怪 = 种族(race) + 子种族(subrace) + 个体变异[](rolled) + 正交 tags[]
```

- **种族 (race) = 基调模板** → 引擎 **main schema**。
  - 定:属性倾向(成长基调)、**装备权限**(能用哪些武器/装备类型,与数值高低解耦——例:哥布林基础属性低,但权限上能用远程武器)、感官/行为风味。
  - 类比:猫科 = 小型肉食哺乳、爪牙攻击、敏锐感官、善伏击、独居。
- **子种族 (subrace) = 在基调上打补丁** → 引擎 **sub schema**。
  - 定:额外成长、特性(如黑暗视觉)、不同基础武器等。
  - 类比:猎豹仍是猫科,但超速强化 + 体型偏大。游戏:洞穴哥布林(种族仍哥布林)= 额外成长 + 黑暗视觉 + 不同基础武器。
- **个体变异[] = 随机层**(见 §3)。
- **正交 tags[] = 跟血统无关的玩法标记**:灵魂(掉灵魂球)、宝宝(适合抓)、…… 部分由 modifier 赋予,部分作者直接挂。

→ 全部映射到引擎已有的 SchemaRegistry / generator / ModifierChain / TagIndex。**引擎成本低,主要是内容结构设计。**

## 3. 个体变异层(自描述的怪物变异条目)

怪物的随机层 = 一组**个体变异条目**(坐在 base+modifier 底座上)。每条是一块**纯数据**,自声明三件事:

1. **适用范围 (eligibility)**:
   - 全局(任何怪都能滚,如 **灵魂**)
   - 限种族(只在某种族滚)
   - 种族列表(在一组种族里滚)
   - 机制 = modifier 声明白名单 / 所需 tag,怪按自己的种族+tag 去合格池 roll(TagIndex 天生支持)。
2. **效果 (effect)**:改属性 / 给抗性(**flat %**,见 §5)/ 挂 tag(灵魂→掉球、宝宝→可抓)/ 改掉落 / 给能力。modifier 是通用 patch。
3. **出现概率 p(level)**:**怪物等级传进来,modifier 自己算出现概率。**
   - 可分级:同一族 modifier 有 T1(早/弱)…T5(晚/强)变体,高级变体的 p(level) 只在高怪等才够大。
   - spawn 流程:按怪的种族/tag 找合格池 → 每个 modifier 用 `p(怪等)` **独立 roll** → 滚出一组 modifiers。

**这套是去中心化的**:没有中央"数量分布";数量是各 modifier 独立概率求和**涌现**的。加一个 modifier = 加它的 `{eligibility, effect, p(level)}`,**系统行为自动更新**。

## 4. 等级 = 唯一难度/奖励主旋钮

- 区域/encounter 决定**怪物等级** → 抬怪等 → 抬所有合格 modifier 的 `p(level)` → 怪更肥(滚出更多/更高级 modifier) → 灵魂/好装/可抓概率更高。
- "解锁更难活动 → 更好产出" 落在**这一个旋钮**(怪等)上,与暗黑"地图等级/深度"一致。

## 5. 显示档位 = 反推(可读性外壳)

- **滚出的 modifier 数量 → 决定显示档位/颜色**(0=普通白、1~2=蓝、3+=黄……)。纯可读性速记:"这只很满"。
- **玩法后果挂具体 modifier,不挂档位**:滚到灵魂就掉球(不管显示啥档)、滚到对应 modifier 就值得抓/掉好装。档位只是涌现出来的一眼提示。
- 反转点:**不是"先定档再 gate 数量",而是"先 roll,数量反推档"。** 拿到暗黑"读得出稀有度"的好处,又保留扁平涌现 roll。

## 6. 跨系统挂钩(养成层守独立)

- **灵魂 modifier** → 怪掉灵魂球(技能升级料)。
- **宝宝 tag** → 怪可抓;抓来后**初始基调**读它的种族/子种族 + 装备权限(例:哥布林宠物属性低但能上远程武器),**但之后的宠物养成系统独立**(梦幻式资质/成长/技能格,不复用玩家灵魂升级树)。守住"众生平等只在战斗/Object 层复用,养成层独立"的红线。
- **抗性 = flat %**(§5 决定):子种族/modifier 直接给百分比(存%、显示%、零公式),负抗显示成"易伤 X%"。与护甲(PoE 曲线)故意分两套数学。

## 7. 抗性表现形态(已定)

- 抗性走**直接百分比**:词缀/子种族 roll "+X% 抗",组件存 X,mitigate 用 `1−X/100`,面板显 X%。**无转换公式。**
- 不走"数值→%带曲线"——那等于给三抗也装护甲那套递减,把故意分开的两套数学缝回去。三抗 = 朴素的人人基础层(flat % + cap 75 的"抗性税"),深度留给护甲(曲线/站位)和元素(稀有)。

## 8. 调参风险(留数值期,不影响结构)

- modifier 越加越多 → 独立概率求和让**期望数量漂高**。对策(择一/组合):每条 `p` 压低、加**软上限**(最多滚 N 条)、按怪等**归一化**。结构不变,纯调参。
