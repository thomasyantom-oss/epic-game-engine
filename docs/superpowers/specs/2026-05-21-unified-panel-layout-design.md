# 统一面板布局设计

## 概述

左上主面板在探索和战斗两种状态间切换内容，不再全屏替换。战斗操作集中在主面板内完成。

## 全局布局（不变）

```
┌────────────────────────┬──────────┐
│      左上（主面板）      │  右上    │
│                        │ 人物/设置 │
├────────────────────────┼──────────┤
│      左下（事件栏）      │  右下    │
│                        │ 快捷行动  │
└────────────────────────┴──────────┘
```

四个面板位置不变，内部内容根据状态切换。

## 左上主面板 — 探索状态

```
┌──────────────────┬─────────┐
│                  │ 地域信息  │
│     地图网格      │ 怪物列表  │
│  (自适应格子)     │ POI按钮  │
│                  │          │
└──────────────────┴─────────┘
```

- 左侧：地图网格，格子自适应面板高度
- 右侧信息栏：
  - 地域层级（如：齐国 > 嘉庆县 > 青羊镇）
  - 周围怪物列表
  - POI 交互按钮（进入村庄等）

## 左上主面板 — 战斗状态

```
┌─────┬───────────┬─────┐
│ ①绿 │ [地形格子] │ ①红 │
│ HP  │  ▶  ▶  ◀ │ HP  │
│ MP  │  ▶     ◀ │ MP  │
│ ②绿 │     ◀    │ ②红 │
│ HP  │           │ HP  │
│ MP  │           │ MP  │
├─────┴───────────┴─────┤
│      [技能栏]          │
│ 攻击 | 防御 | 技能 | 道具 │
└───────────────────────┘
```

### 战场区域（中间）
- 3×3 格子，取当前地图位置周围的地形颜色渲染
- 我方标记：绿色三角 ▶（朝右），带序号
- 敌方标记：红色三角 ◀（朝左），带序号
- 序号与左右状态栏对应

### 状态栏（左右）
- 左侧：我方单位列表（绿色系）
- 右侧：敌方单位列表（红色系）
- 每个单位显示：序号 + 名称 + HP 条 + MP 条
- 上下居中排列，每侧最多 9 个单位（3×3 满员时）

### 指令栏（下方，分步操作）

分为 2-3 块，按操作流程展开：

**第一块：当前角色 + 基础指令**
- 显示当前行动的我方角色名
- 指令选项：攻击 / 防御 / 技能 / 道具 / 逃跑

**第二块：详情选择（根据第一步展开）**
- 攻击 → 显示可攻击目标列表
- 技能 → 显示技能列表 → 选中后显示目标列表
- 道具 → 显示可用道具列表 → 选中后显示目标列表
- 防御/逃跑 → 无需第二步，直接确认

**第三块（可选）：确认/取消**
- 可返回上一步重新选择

### 站位系统
- 3×3 格子：3 列（前/中/后）× 3 行
- 我方前排靠右（靠近敌方），后排靠左
- 敌方前排靠左（靠近我方），后排靠右
- 角色站位在人物面板中预设（行+列偏好）

### 地形格子渲染
- 取当前玩家位置为中心的 3×3 区域地形
- 每格背景色用对应地形颜色（不显示地形汉字）
- 纯视觉效果，不影响战斗机制

## 左下事件栏

- 探索时：移动描述 + 危险度颜色
- 战斗时：战斗日志（谁攻击了谁、伤害数值等）

## 右下快捷行动栏

- 探索时：快捷按钮（骑乘、使用道具等）
- 战斗时：可放道具快捷使用，或留空

## 右上面板

- 不变：人物信息 / 设置
- 人物面板新增：战斗站位预设（选择前/中/后排 + 行位置）
