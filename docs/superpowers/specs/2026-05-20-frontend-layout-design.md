# 前端界面布局设计

## 整体布局

页面采用 4×3 网格（与屏幕同比例），所有面板带边框，支持 tab 切换。

```
┌─────────────────────────┬─────────┐
│                         │         │
│      主窗口 (3×2)       │ 功能页面│
│                         │  (1×2)  │
│  - 大地图缩略版         │         │
│  - 场景文字/探索        │ [人物]  │
│                         │ [属性]  │
│                         │ [...]   │
├─────────────────────────┼─────────┤
│      日志 (3×1)         │ 额外    │
│                         │ (1×1)   │
│  - 事件记录             │placeholder│
└─────────────────────────┴─────────┘
```

## 面板定义

### 主窗口（左上，3×2）

- 占据页面左上方大部分区域
- 带 tab 支持，可切换不同视图（如：场景 / 大地图 / 战斗）
- 默认显示当前场景（彩色文字 + 操作链接）

### 功能页面（右上，1×2）

- 带 tab 栏，可在多个功能之间切换
- 预期 tab：人物、属性、背包、技能等（后续扩展）
- 每个 tab 是独立内容区

### 日志（左下，3×1）

- 显示游戏事件文字记录
- 自动滚动到最新
- 可能也带 tab（如：全部 / 战斗 / 系统）

### 额外区域（右下，1×1）

- Placeholder，预留扩展
- 未来可能放：小地图、快捷操作、队伍信息等

## 通用规则

- 所有面板有边框（样式/颜色可通过设置自定义）
- 所有面板支持 tab 切换机制
- Tab 样式统一，点击切换内容
- 面板大小比例固定，跟随窗口缩放
- 布局通过 CSS Grid 实现
