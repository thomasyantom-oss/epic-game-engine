# 战斗系统设计

## 概述

基于 JRPG 指令菜单 + 宝可梦式同时下令速度结算的回合制战斗系统。强调决策深度和技能联动的连击感。战斗引擎模块化，以下为基础 Mod 的默认配置。

## 战斗触发

- **明雷：** 场景中的可点击动作触发（如"攻击哥布林"）
- **暗雷：** 进入特定场景自动触发战斗

## 参与者与阵列

### 站位系统

双方相对站位，面对面：

```
【我方】                 【敌方】
后  中  前    ←对峙→    前  中  后
```

- 3 排 × 3 位 = 每方最多 9 个单位
- 单位可占多格（大体型怪物可能 2×2 甚至 3×3）
- 战斗中位置不移动、不补位
- 前排阵亡后中排不会前移，位置固定
- 只显示有人的位置，不显示空格
- 角色有站位偏好，布阵时默认按偏好站位，玩家可手动调整

### 排与排关系

- 排之间的承伤/加成关系可配置（具体数值待定）
- 架构支持灵活定义排间效果

## 回合流程

1. **下令阶段：** 玩家逐个给己方角色选择指令
2. **结算阶段：** 全部下令完毕后，所有单位（含敌方）按速度排序统一执行
3. **演出阶段：** 结算过程以文字形式在日志面板展示
4. **判定阶段：** 检查胜负条件

敌方行动由 AI 决定，玩家不可见敌方本回合指令。

## 指令菜单

JRPG 式层级菜单：

- **攻击** — 普通攻击，打最近有人的排
- **技能** — 展开技能列表，各技能有不同范围/效果
- **道具** — 展开背包可用道具
- **防御** — 本回合减伤

## 攻击范围

- **普通攻击：** 由近及远，攻击对方最近的有人的排中的目标
- **技能：** 各自定义作用范围（单体/一排/全体/指定排/自身等）
- 前排存活时保护中后排不被普通攻击触及

## 联动系统

三套独立系统，可交叉影响：

### 状态标签

- 技能可施加状态标签到目标或自身（破甲、点燃、冰冻等）
- 其他技能检测标签时触发增强效果
- 用于角色间联动和对敌控制链
- 标签可配置：持续回合数、可叠加层数、互斥关系

### 资源累积

- 角色自身的连招资源（连击点、能量、怒气等）
- 特定技能积累资源，终结技消耗资源
- 资源类型由职业/角色定义
- "攒满释放"的爽快感

### 技能链

- 配置"A 之后可接 B"的 combo 路径
- 命中技能链内的后续技能自动增强（伤害加成、额外效果等）
- Combo 路径清晰，给玩家明确的连招目标

## 数值体系

- 小数字精确型：HP 几十到几百，伤害个位到十位
- 每一点数值都有意义
- 具体公式由 Mod 配置定义

## 战败处理

- 全队阵亡 = 战斗失败
- 失败后撤退到安全区域
- 受到惩罚（损失金钱/经验/道具等，具体由 Mod 配置）
- 不会 Game Over，不需要读档

## 战斗界面布局

利用已有的 4×3 网格面板系统：

```
┌─────────────────────────┬─────────┐
│      主窗口 (3×2)       │行动选择 │
│                         │ (1×2)   │
│  双方阵列展示           │         │
│  汉字+颜色             │ [攻击]  │
│                         │ [技能→] │
│                         │ [道具→] │
│                         │ [防御]  │
├─────────────────────────┼─────────┤
│    战斗日志 (3×1)       │当前角色 │
│                         │ (1×1)   │
│  "战士对哥布林使用       │ HP: 45  │
│   破甲斩，造成12伤害"   │ MP: 20  │
└─────────────────────────┴─────────┘
```

- 主窗口：双方阵列，汉字代表角色，颜色代表状态
- 右上：当前下令角色的行动选项
- 左下：战斗过程文字演出
- 右下：当前行动角色的状态面板

## 引擎可扩展性

以上所有机制均为基础 Mod 默认配置。引擎层模块化设计：

- **回合流程控制** — 可替换（默认：同时下令+速度结算）
- **行动资源系统** — 可替换（默认：JRPG 指令菜单无额外资源限制）
- **伤害计算系统** — 可替换（默认：小数字精确型）
- **效果/状态系统** — 可替换（默认：标签+资源+技能链三套）
- **胜负判定** — 可替换（默认：一方全灭）
- **AI 行为** — 可替换（默认：基于规则的简单 AI）

Mod 可以替换任意模块实现完全不同的战斗体验。
