# 地图面板布局改造设计

## 概述

将地图面板内部改为左右分栏：左侧地图（格子自适应大小），右侧区域信息栏。交互按钮从右下角操作面板挪到地图旁边的信息栏，减少视线跳转。

## 布局

地图面板（左上 panel-main）内部分栏：
- 左侧 ~65%：地图网格，格子大小根据可用高度动态计算（面板高度 ÷ 地图行数）
- 右侧 ~35%：区域信息栏

战斗时仍然整体替换为 CombatView，不受影响。

## 格子自适应

- 格子大小 = 面板可用高度 ÷ 显示的行数（viewportSize）
- 移除固定 2.2rem，改为动态计算
- 确保格子始终为正方形（width = height）
- 面板宽度不够时，格子按较小维度计算（取 min(按高算, 按宽的65%算)）

## 区域信息栏内容

从上到下：
1. **区域名称** — 地图名（如"主世界"）
2. **当前坐标** — (x, y) 显示
3. **地形图例** — 所有地形类型的颜色方块 + 汉字 + 名称对照
4. **可交互按钮** — POI 操作（进入村庄等），从右下角操作面板挪到这里

## 操作面板（右下）变化

- 保留方向键 D-pad
- 移除 POI 交互按钮（已挪到地图信息栏）
- 将来可放其他内容（背包快捷栏等）

## 事件栏（左下）变化

- 危险度信息融入移动事件文字，用颜色区分。如："你来到了草地。这里看起来很<span style='color:green'>安全</span>。"
- 不单独显示危险度 UI 组件

## 实现范围

1. MapGrid.vue：格子自适应大小（基于容器尺寸计算）
2. 新建 MapInfoPanel.vue：区域信息栏组件
3. App.vue：地图 tab 内左右分栏布局
4. NavigationPanel.vue：移除 POI 按钮（只保留 D-pad）
5. 事件栏文字增加危险度颜色描述
